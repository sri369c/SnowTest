# SnowTest v2.0.0

## Highlights

- Data now survives restarts: each database is saved as a DuckDB file.
- Several SnowTest instances can run side by side.
- Much wider Snowflake SQL support.
- Verified to work with dbt.

## ✨ New features

### Data that survives restarts
- Set `SNOWTEST_DATA_DIR` (or `--data-dir`) to keep data. Each database is saved as `<dir>/<name>.duckdb`.
- Stage definitions are saved in `<dir>/stages.json` and reloaded at startup.
- `setup.py` keeps data by default. Pass `--no-persist` to run in memory and start clean each time.
- `DROP DATABASE` deletes the database file. `DROP DATABASE` and `DROP SCHEMA` also remove the stages inside them.
- `POST /_snowtest/reset` now deletes saved files as well.

### Running several instances
- New `--name`, `--port` and `--network` flags. Each instance gets its own data volume (`<name>-data`) and stage directory (`.snowtest/<name>/stages`).
- New `setup.py` commands: `redeploy` and `reset`.
- New flags shared by every `setup.py` command: `--persist`/`--no-persist`, `--image`, `--stage-root`, `--public-key`, `--users`, `--env KEY=VALUE`, `--engine` and `--dry-run`.

### SQL support
- **New functions:** `IFF`, `NVL`, `NVL2`, `ZEROIFNULL`, `NULLIFZERO`, `DIV0`, `EQUAL_NULL`, `DECODE`, `DATEADD`, `DATEDIFF`, `CONVERT_TIMEZONE`, `ARRAY_CONSTRUCT`, `OBJECT_CONSTRUCT` and `PARSE_JSON`.
- **Conversion functions:** `TO_VARCHAR`/`TO_CHAR`, `TO_DATE`, `TO_TIMESTAMP[_NTZ|_LTZ|_TZ]`, `TO_NUMBER`/`TO_DECIMAL`/`TO_NUMERIC`, `TO_DOUBLE`, `TO_BOOLEAN` and `TO_BINARY`, each with a `TRY_` version. Snowflake date/time formats are translated.
- **JSON paths:** Better `v:a.b` handling, including quoted keys and paths cast to string.
- **Ordered aggregates:** `LISTAGG` and `ARRAY_AGG ... WITHIN GROUP (ORDER BY ...)`.
- **Current date and time:** `CURRENT_TIMESTAMP`, `LOCALTIMESTAMP`, `CURRENT_TIME`, `LOCALTIME`, `CURRENT_DATE` and `SYSDATE`.

### Compatibility
- **dbt:** Verified against dbt-core 1.12.6 and dbt-snowflake 1.12.4.
  - Supported: seeds, views, tables, incremental `merge`/`delete+insert`/`append`, enforced contracts, snapshots, tests, source freshness, docs and `run-operation`.
- **Driver protocol:** Accepts gzip-encoded request bodies.
- **Python connector:** `snowflake-connector-python` 5.1 is pinned in the tests. Versions 3.16 and 4.8 were checked manually.

### Configuration
- New `SNOWTEST_ROLE` setting, which defaults to `SYSADMIN`.

## ⚠️ Breaking changes

- **Stricter startup:** Bad settings now stop the server instead of falling back to defaults. This covers unknown flags, flags missing a value, ports outside 1–65535, and invalid `SNOWTEST_VERBOSE` values.
- **Numbers:** `NUMBER`, `DECIMAL` and `NUMERIC` without a scale are now `NUMBER(38,0)`. For example, `'1.5'::number` now returns `2`.
- **Time precision:** A `TIME` or `TIMESTAMP` precision the engine can't store now raises an error instead of returning wrong results.
- **Saved data by default:** `setup.py` now keeps data between restarts. Use `--no-persist` to keep the old in-memory behaviour.

## 🚫 Not supported

- Dynamic tables, materialized views, Python models, `CLONE`, Iceberg tables and `GRANT`-based `grants:` configs.

## 🧪 Tests

- More engine, dialect and configuration tests.
- Updated the dbt and connector compatibility test scripts.

## 📦 Packaging

- Image version is now `snowtest:2.0.0`.
- Updated `Dockerfile` and `compose.yaml`.
