# snowtest v3.0.1

Fixes navigation from Home → Live state into the catalog browser. Only the HTML pages changed; the Snowflake protocol, SQL and storage are the same as in 3.0.0.

## Fixed

- **Schema and table preview pages now stay under Home → Live state.** In 3.0.0, opening a schema from the Live state tab showed a page without Home's tabs, and its breadcrumb led back to Overview instead of Live state. Now the schema, table preview and "not found" pages under `/browse`:
  - highlight **Home** in the top nav;
  - show Home's tab row (Overview · Live state · Connect · What it speaks · Control plane) with **Live state** selected; each tab links to that section of Home;
  - start the breadcrumb with **← Live state**, linking to `/#live`;
  - offer **Back to live state** on the "not found" page, instead of "Back to the overview".

## Changed

- Removed the schema page footer that linked to `/operations`, matching the other pages. The preview page's note on how many rows it shows stays, as a plain line under the table.

## Upgrading

```bash
./setup.py redeploy          # rebuilds as snowtest:3.0.1, keeps the data volume
# or by hand
podman build -t snowtest:3.0.1 .
```

The default image tag in `setup.py`, `compose.yaml` and the README is now `snowtest:3.0.1`.
